# Оно тебе надо

Проектная работа «Оно тебе надо» — аукцион вещей, в которые никто не верил.

Одностраничный сайт, свёрстанный по макету из Figma: семантическая разметка HTML, стилизация CSS (гриды, флексбокс, позиционирование, оверлеи), шрифт Raleway.

## Структура проекта

- `index.html` — разметка страницы;
- `styles/global.css` — глобальные стили;
- `styles/style.css` — основные стили;
- `fonts/` — шрифты и их подключение;
- `images/` — изображения.
